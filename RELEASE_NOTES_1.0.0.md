# Agent Sandbox 1.0.0

First 1.x release, for the AgentWorks BOM 1.22.0. The version moves to 1.0.0 with the other AgentWorks members. The
API is the same as 0.10.2.

## Changes

- Jackson goes to 2.22.3, which fixes the jackson-core HIGH (CVSS 7.5) in 2.22.2. Agent Sandbox has no Jackson 3
  dependency.
- The licence text and source headers now match the canonical Business Source License 1.1 text in the root `LICENSE`.
  The terms are unchanged.

The exact consumer-rooted CycloneDX SBOM for each module is certified and published by the shared AgentWorks release
procedure.
